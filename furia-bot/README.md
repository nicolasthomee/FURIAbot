# FURIA Bot 🔥

Um bot do Telegram feito para os fãs da FURIA Esports!

## Comandos disponíveis

- `/start` — Mensagem de boas-vindas
- `/frase` — Receba uma frase motivacional
- `/curiosidade` — Descubra curiosidades sobre o time

## Como rodar

1. Clone este repositório
2. Crie um `.env` com seu token do Bot
3. Instale as dependências: `pip install -r requirements.txt`
4. Rode o bot: `python bot.py`
